# Modelos de Linguagem de Grande Escala: Teoria, Implementação e Aplicações

Aqui você irá encontrar todos os código do livro "Modelos de Linguagem de Grande Escala: Teoria, Implementação e Aplicações".

A estrutura de pasta é dívida pelos capítulos do livro. Caso queira encontra o código de um capítulo específico, basta navegar até a pasta correspondente.

Por exemplo para encontrar o código do capítulo 1, navegue até a pasta `capitulo_1`. E caso esteja procurando de um subcapítulo, como o 1.1, navegue até a pasta `capitulo_1/capitulo_1_1`.
