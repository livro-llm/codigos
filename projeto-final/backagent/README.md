# API do agente

A API do agente é responsável por gerenciar as interações com o agente, incluindo a criação de tarefas, a consulta de status e a obtenção de resultados. Ela utiliza o framework FastAPI para criar endpoints RESTful que permitem a comunicação com o agente.

## Instalação

```bash
uv add Flask Flask-SocketIO Flask-Cors Flask-SQLAlchemy python-dotenv pydantic stripe psycopg2-binary google-auth flask-jwt-extended
```
